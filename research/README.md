# Void-eager Research Library

This directory contains the research basis used to design the serious-game mechanic.

## Evidence layers

1. **Autism target/profile** — evidence about cognitive flexibility, task transitions, and autistic inertia.
2. **Interruption/resumption mechanism** — experimental HCI/cognitive research on interruptions, preparation, retrieval cues, and resumption lag.
3. **Serious-game/intervention structure** — autism/neurodiversity studies showing how cognitive training, compensatory strategies, metacognitive coaching, adaptation, and reflection have been implemented.

These layers must not be treated as interchangeable. A general interruption study is not autism-specific evidence; an autism descriptive study is not proof that a particular game mechanic is therapeutic.
