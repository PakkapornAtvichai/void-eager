# Team Ownership

## User / project lead
- scope decisions
- accepts/rejects cuts
- playtest observation
- presentation priorities
- final demo call

## ChatGPT
- research synthesis and claim boundaries
- gameplay/system documentation
- content and dialogue support
- implementation review
- scope control
- Yoko handoff coordination

## Coding agent
- implementation from explicit tickets
- local testing/build fixes
- no feature invention outside ticket scope
- report blockers rather than silently broadening architecture

## Yoko
- visual direction
- character/environment/UI art
- exports for the current gameplay-loop packet
- broader world design may continue, but current-loop assets take production priority

## Decision rule
If a proposed feature is not required to demonstrate the core loop in three days, it is backlog by default.
