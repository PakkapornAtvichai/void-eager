# 3-Day Roadmap

## Day 1 — Prove the loop
Deliver a browser app shell with one investigation screen, one interruption, Quick Pin, a short secondary task, return/resume, and placeholder deduction.
Use placeholders. Do not wait for final art.
Freeze the research framing and wording.

Exit criteria:
- app runs locally;
- player can complete the loop once;
- Quick Pin visibly preserves context;
- no blocker prevents Day 2 content integration.

## Day 2 — Complete the Coupler slice
Implement the real Coupler evidence sequence, Storage cross-check, final deduction, and first Yoko asset packet.
Add minimal dialogue only where it clarifies the loop.
Instrument simple event logging for playtest observations.

Exit criteria:
- beginning-to-end slice is playable;
- all P0 assets are integrated or have placeholders;
- deduction is understandable without instructor explanation.

## Day 3 — Validate and present
Run rapid playtests, fix comprehension/pacing/bugs, add reflection, polish transitions and presentation.
Only add a second puzzle if all P0 criteria are already green.

Exit criteria:
- stable demo build;
- 5–10 minute run;
- research slide/handout claims match sources;
- fallback build works with placeholder art if needed.
