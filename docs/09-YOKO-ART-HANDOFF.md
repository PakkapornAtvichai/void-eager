# Yoko Art Handoff

## Working principle
Yoko can continue developing the wider Void-eager visual identity, but implementation requests arrive as one gameplay-loop packet at a time.

## Loop 01 — Coupler: required assets
- Maintenance terminal/background
- work-order/maintenance-record treatment
- Quick Pin UI treatment
- interruption notification treatment
- secondary-task panel treatment
- Storage background
- new coupler object/inspection view
- evidence-card treatment
- deduction panel
- reflection panel
- Glint portrait only if dialogue is included

## Nice to have
- ambient ship details
- small UI icons
- transition animation
- sound-cue visual hooks
- alternate object states

## Not required for Loop 01
- finished Bridge
- finished Science Lab
- full ship map
- Maven full character sheet
- Aegis animation
- Solace room
- six-room navigation art
- additional suspect portraits

## Asset handoff convention
Put raw/in-progress files in `assets/incoming-yoko/`.
Move implementation-approved exports to `assets/approved/`.
Use `assets/placeholders/` for temporary implementation stand-ins.

## Export request
Prefer web-ready PNG/WebP/SVG as appropriate, transparent backgrounds for isolated objects, and stable filenames. Do not block implementation on final polish.
